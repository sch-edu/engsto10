# WordQuest: English Empire

A dependency-free browser game for Class 10 English (184) – Module 1: A Letter to God, Dust of Snow, Fire and Ice.

Run locally: `cd wordquest && python3 -m http.server 8080` then open http://localhost:8080.

Games: Keyword Sniper, Value Point Collector, Answer Architect (AQS scoring), Character Mind Reader, Irony & Humour Detector, Poetry Decoder Lab (Dust of Snow).
Progress (XP, rank, streak, badges) is saved in the browser's localStorage.
